Carica i tuoi pezzi

Lo zip e la cartella sostituiscono le categorie che contengono; i file di una categoria sostituiscono solo quella.

Come si prepara un kit

  • Una cartella per categoria: faccia/ occhi/ sopracciglia/ bocca/ accessori/
  • Ogni pezzo è un file SVG o PNG trasparente; il nome del file è il nome del pezzo.
  • Tutti i pezzi sulla stessa tavola quadrata, per esempio 1000 × 1000, con lo stesso centro: si sovrappongono senza aggiustamenti.
  • Disegna ogni pezzo dove starà sulla faccia (gli occhi in alto, la bocca in basso) e lascia vuoto il resto della tavola.
  • Il fondo resta trasparente: il colore della carta lo mette il tool.
